# Testbench

[`test.py`](test.py) is a [cocotb](https://docs.cocotb.org/en/stable/) test. It replays the 704 design's reference
trace (1,271 branches) through the pins with the handshake described in the main README and checks the number of
mispredictions of every predictor: perceptron 229, bimodal 421, gshare 172, tournament 142
(81.98 / 66.88 / 86.47 / 88.83%). It also fails on any X or Z on the outputs.

`tb.v`, `Makefile` and `test.py` are generated by Vulkos; change them there, not here.

## Run it

RTL simulation (Icarus Verilog):

```sh
make -B
```

Gate level: copy the hardened netlist (`runs/wokwi/final/pnl/tt_um_kyrylo_nazarevych_bp.pnl.v` or the
`gate_level_netlist.v` artifact of the GitHub Actions run) to `gate_level_netlist.v`, then:

```sh
make -B GATES=yes
```

Waveforms: `gtkwave tb.fst tb.gtkw` or `surfer tb.fst`.
